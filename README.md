# CarExpenses — Облік витрат на автомобіль

**Обрана тема:** Витрати на автомобіль (Тема № 14).

Консольний крос-платформний застосунок на платформі .NET 10 для ведення обліку витрат на утримання автомобіля (заправка, обслуговування, штрафи) та розрахунку вартості кілометра пробігу.

## Як запустити
```bash
dotnet run --project CarExpenses
```
